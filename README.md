# 32-bit-RISC-V-processor-with-5-stage-pipeline-architecture-integrated-with-2-bit-vedic-multipler
Tools: Verilog, Xilinx Vivado, Built a five-stage processor structure covering IF, ID, EX, MEM and WB Integrated a 2-bit Urdhva Tiryakbhyam Vedic multiplier into the execution stage. Used a Verilog testbench to simulate instruction execution and arithmetic operations.
